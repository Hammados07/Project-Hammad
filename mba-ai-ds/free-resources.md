# 📚 Free Resources: Master List

Everything here is **free to learn from**. Some offer a paid certificate (e.g. NPTEL's proctored exam, ~₹1,000; IIMB SWAYAM exams) that is optional.

> **Tip for NPTEL:** go to **nptel.ac.in** (or onlinecourses.nptel.ac.in / swayam.gov.in) and search the course title. Every course's lecture videos are also on the **NPTEL YouTube channel**. Watch at 1.25x.

## 🌍 Global free courses & books

### Statistics & Maths
- **Khan Academy:** Statistics & Probability; Linear Algebra; Calculus (only if needed)
- **StatQuest with Josh Starmer** (YouTube): stats & ML, extremely clear
- **OpenIntro Statistics** (free PDF): openintro.org
- **3Blue1Brown** (YouTube): *Essence of Linear Algebra*, *Neural Networks*

### Python, R, SQL
- **Harvard CS50P**: Python (cs50.harvard.edu/python)
- **Kaggle Learn**: Python, Pandas, Data Cleaning, Data Viz, Intro/Intermediate ML, SQL, Advanced SQL, Feature Engineering, ML Explainability
- **Python Data Science Handbook**: Jake VanderPlas (free online)
- **R for Data Science (2e)**: r4ds.hadley.nz
- **SQLBolt** (sqlbolt.com) · **Mode SQL Tutorial** · **pgexercises.com** (PostgreSQL practice)

### Machine Learning & AI
- **ISLP**: *An Introduction to Statistical Learning with Applications in Python*, free PDF + videos at statlearning.com
- **Google Machine Learning Crash Course**
- **fast.ai**: Practical Deep Learning for Coders
- **Andrej Karpathy**: *Neural Networks: Zero to Hero* (YouTube)
- **Hugging Face LLM Course**
- **DeepLearning.AI short courses** (free, 1–2 hrs each)
- **Anthropic prompt engineering interactive tutorial** (GitHub) + Anthropic Academy
- **Made With ML**: MLOps
- **Elements of AI**: non-technical AI + ethics

### Forecasting, Optimisation, Big Data
- **Forecasting: Principles and Practice (3rd ed.)**: otexts.com/fpp3 (R), plus the Pythonic edition on the same site
- **PuLP docs** + **SciPy optimize docs**
- **Databricks Free Edition**: free Spark notebooks
- **Google Colab**: free Python notebooks in the browser

### Business, Finance, Strategy
- **Zerodha Varsity** (Indian markets, accounting, personal finance), free
- **Aswath Damodaran** (NYU): corporate finance & valuation classes on YouTube
- **Khan Academy / Marginal Revolution University**: economics
- **Finshots**: daily 3-minute Indian business news
- **Victor Cheng's case interview videos**: consulting thinking
- **Microsoft Learn**: PL-300 Power BI path

### ⚠️ Learning trap to avoid
**Don't collect courses. Finish them.** For each module, pick **one main resource** (the first one listed in the module) and only use the others when you're stuck.

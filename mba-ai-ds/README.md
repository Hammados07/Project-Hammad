# 🎓 MBA in AI & Data Science: Rebuilt From Scratch (Simple Edition)

A **4-semester, 28-module, 48-week** course to relearn everything from my MBA (AI & Data Science), explained simply, practised with code, and **taught back on YouTube**.

> 🧒 **Like I'm 5:** An MBA teaches you **how a business works** (how it makes money, sells things, pays people, beats competitors).
> AI & Data Science teaches you **how to use numbers and computers to make better business decisions**.
> Put together: *"Use data to help a business make more money and fewer mistakes."* That's the whole degree in one sentence.

---

## 1. How this course was built (research basis)

I looked at how India's top programmes structure the same material and merged them into one path:

| Programme | What it taught me about structure |
|---|---|
| **IIM Ahmedabad / IIM Bangalore PGP (MBA) first year** | All compulsory **business core**: financial accounting, economics (micro + macro), marketing, organisational behaviour/HR, operations, quantitative methods, communication, strategy, law/ethics, managerial computing. Electives come in year 2 |
| **PGDBA, jointly run by IIM Calcutta, ISI Kolkata & IIT Kharagpur** (India's flagship business-analytics programme) | A clear **three-stage order**: **ISI → statistics foundations** (probability, statistical structures in data, inference, computing for data science, databases), then **IIT Kharagpur → technology and machine learning** (regression & time series, algorithms, ML, operations modelling), then **IIM Calcutta → business applications** (data mining, marketing analytics, finance analytics). Ends with an internship/capstone |
| **IIT Delhi (DMS) MBA** | Year 1: functional core + quantitative methods, business research methods, information systems. Year 2: specialisation electives such as analytics |
| **IIT Madras BS in Data Science** | A modern ladder for the tech side: foundation maths & statistics → Python → databases → ML foundations → ML techniques → deep learning, big data and LLMs |
| **NPTEL / SWAYAM (IIT & IIM free courses)** | The **free lecture videos** used as the main resource for most modules (see `free-resources.md`) |

**The result:** Semester 1 = business basics + numbers + coding basics. Semester 2 = core management + statistics. Semester 3 = data science & machine learning. Semester 4 = advanced AI, strategy and a capstone. This follows the same **foundations → tools → applications → integration** order as the PGDBA, with IIM-style business modules woven through every semester, so the **business sense grows alongside the tech**.

> Course names and structures change year to year. This is a learning path *modelled on* those programmes, not an official copy of any syllabus.

## 3. Every module follows the same pattern (so the brain knows what to expect)

Each module in `semester-N.md` has these 8 parts. **This is also the structure of your YouTube episode** for that module.

| Part | What it is | Why |
|---|---|---|
| 🧒 **Like I'm 5** | One simple analogy | Gives your brain a hook to hang details on |
| 🎯 **Key concepts** | 5–10 ideas, one line each | The 20% that gives 80% of understanding |
| 🧠 **Remember it** | A mnemonic or picture | Makes it stick |
| 📐 **Formula / pattern** | The one formula or code pattern to know | You'll use it for real |
| 📺 **Free resources** | 1 main course + backups | Learn from IIT/IIM professors for free |
| 🛠️ **Build it** | Lab file or exercise | You only understand what you've built |
| 🎥 **Teach it** | YouTube episode title + hook | Teaching is the best way to remember |
| ✅ **Self-test** | 3–5 questions | Check before moving on |

## 4. The 48-week timetable

**Weekly rhythm** (fits `growth-plan/02-schedule-and-timetable.md`, ~6–7 hrs/week of study):

| Day | Block | What |
|---|---|---|
| Mon | 60 min (morning) | 📺 **Learn**: watch lectures / read the module |
| Tue | 60 min | ✍️ **Understand**: notes in your own words + Anki cards |
| Wed | 60 min | 🛠️ **Build**: run the lab / exercise |
| Thu | 60 min | 📺 **Learn** the next part |
| Fri | 60 min | 🛠️ **Build** + self-test |
| Sat | 2 hrs (morning) | 🎥 **Teach**: record the week's episode |
| Sun | 30 min | 🔁 **Review**: Anki + weekly review |

## 5. The Learn → Build → Teach loop

```
   📺 LEARN (free IIT/IIM lecture)
        │
        ▼
   ✍️ EXPLAIN IT SIMPLY (notes, "like I'm 5")
        │
        ▼
   🛠️ BUILD IT (lab code / Excel / SQL in this repo)
        │
        ▼
   🎥 TEACH IT (YouTube episode + Reels)
        │
        ▼
   🔁 REVIEW (Anki flashcards, spaced repetition)
        └──────────► next module
```

Teaching forces you to find the gaps in your own understanding. **Every gap you find while scripting a video = a thing you would have forgotten.** That's why this course and your YouTube channel are **the same project**.
